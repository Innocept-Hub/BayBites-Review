# BayBites - Customer Feedback & Review Portal

A fast, elegant customer feedback portal designed for **BayBites Dubai**. Includes a standalone single-file HTML version with an embedded offline Base64 logo, plus an interactive React SPA with direct WhatsApp submission.

## Features

- **Embedded Offline Logo**: High-resolution BayBites logo embedded directly as a Base64 data URI—no broken external image links.
- **Dining Type Switcher**: Dine-in, Takeaway, and Delivery modes with contextual Table No. and Server Name fields.
- **Overall Satisfaction**: Interactive emoji satisfaction selector (Dissatisfied, Neutral, Satisfied).
- **5-Star Rating**: Dynamic star rating with live verbal rating labels.
- **Detailed Service Breakdown**:
  - Food & Taste
  - Service Speed & Hospitality
  - Ambiance & Atmosphere
  - Cleanliness & Hygiene
  - Value for Money
- **Customer Information & Occasions**: Name, phone, email, date of visit, and special occasions (Birthday, Anniversary, Business Lunch, Family Gathering).
- **Direct WhatsApp Dispatch**: Automatically formats a clean, structured feedback receipt and sends it directly to BayBites WhatsApp (`+971 55 426 6044`).
- **Single-File Self-Contained HTML**: `BayBites-Feedback-SingleFile.html` can be double-clicked and opened in any browser offline without a web server.

## Getting Started

### Run the Web App
```bash
npm install
npm run dev
```

### Build for Production
```bash
npm run build
```

### Standalone HTML
Open `BayBites-Feedback-SingleFile.html` directly in any web browser.
